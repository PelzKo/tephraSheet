# Wiki and languages

- The **wiki** search finds rules, specialties, augments, racial traits, catalog items, these help pages and the pages players wrote. The search box in the header works on every page.
- **Anyone can write pages** (house rules, places, people). Every edit keeps the previous version: **History** on a page lists them and compares any of them with the current text; the narrator can restore a version with one click (the replaced text stays in the history) or delete pages.
- If someone else saved the page while you were editing, your save is refused and both texts are shown; copy what you need, then save again.
- **Links between pages:** `[[Page title]]` links a wiki page (a missing page opens the new-page form), `[[Page title|text]]` changes the link text, `[[spec:Battle Theme]]`, `[[aug:…]]` and `[[trait:…]]` link a specialty, augment or racial trait. Images only load from this site; other image addresses are shown as links.
- **Printing** a wiki, help or rules page leaves out the navigation (A4).
- **Language:** choose it in the top right corner. The choice is remembered in this browser. Rule texts (specialties, augments, traits) are translated too. More languages can be added later by adding translation files (`locale/<code>/` and `rules/data/i18n/<code>/`).
