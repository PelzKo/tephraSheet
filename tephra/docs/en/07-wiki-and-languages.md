# Wiki and languages

- The **wiki** search finds rules, specialties, augments, racial traits, these help pages and the pages players wrote.
- **Anyone can write pages** (house rules, places, people). Every edit keeps the previous version; the narrator can restore or delete pages.
- **Language:** choose it in the top right corner. The choice is remembered in this browser. Rule texts (specialties, augments, traits) are translated too. More languages can be added later by adding translation files (`locale/<code>/` and `rules/data/i18n/<code>/`).
