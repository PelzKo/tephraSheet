# Planner

Open **Planner** from the sheet tabs to plan coming levels before you reach them.

- For each future level choose the skill points (+2 / +1 / +1), a specialty, augments to learn and a note.
- The plan table checks whether each planned specialty can be learned at that point (✓ or the missing requirement).
- **Preview** compares your values now with the values after all planned levels.
- When you level up, the plan for that level is **preselected** – you can still change everything.
